引言

知识点概览

1. 路由树

Gin 使用 Radix 树（基数树）实现高效的路由匹配。

2. 路由注册

支持 GET、POST、PUT、DELETE 等 HTTP 方法的路由注册。

3. 路由分组

使用路由组管理相关的路由。

4. 参数路由

支持动态路由参数和通配符。
