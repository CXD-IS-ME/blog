引言

知识点概览

1. 分页查询

使用 LIMIT 和 OFFSET 实现分页，同时返回总数用于计算页数。

2. 关键词搜索

使用 LIKE 查询或全文索引实现关键词搜索。

3. 标签筛选

结合标签关联表进行筛选。

4. 排序
