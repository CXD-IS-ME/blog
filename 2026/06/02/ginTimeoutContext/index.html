超时控制与优雅降级：Context 包实现

引言

在高并发场景下，超时控制是保证系统稳定性的关键。Go 语言的 context 包提供了强大的上下文管理能力，可以实现超时控制、取消信号传递等功能。本文将介绍如何在 Gin 项目中使用 context 包实现超时控制和优雅降级。

知识点概览

1. Context 概述

context.Context 是 Go 语言中用于传递请求范围的值、取消信号和截止时间的接口。

2. context.WithTimeout

创建一个带有超时时间的 context，超时后自动取消。

3. 超时传递

context 可以通过函数调用链传递，子 context 会继承父 context 的取消信号。

4. 优雅降级

当请求超时或出错时，返回默认值或降级响应。
