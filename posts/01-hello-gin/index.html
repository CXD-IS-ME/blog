Gin 初体验：5分钟搭建第一个 Web 服务

2026-06-01

引言

在 Go 语言的 Web 框架中，Gin 以其高性能、简洁的 API 和丰富的功能成为最受欢迎的选择之一。它基于 httprouter，具有出色的路由性能，同时提供了中间件支持、参数绑定、JSON 响应等现代化 Web 开发所需的功能。

本文将带你从零开始，在 5 分钟内搭建一个完整的 Gin Web 服务。

安装 Go 环境

首先确保你已安装 Go（建议 1.16+）：

go version
# go version go1.21.0 windows/amd64

如果未安装，可从 Go 官网 下载安装。

安装 Gin

使用 go get 安装 Gin：

go get -u github.com/gin-gonic/gin

这会将 Gin 下载到你的 $GOPATH/pkg/mod 目录。

创建第一个 Gin 服务

创建 main.go 文件：

package main

import "github.com/gin-gonic/gin"

func main() {
    // 创建 Gin 路由器实例
    r := gin.Default()

    // 定义路由：GET 请求，路径为 "/"
    r.GET("/", func(c *gin.Context) {
        // 返回 JSON 响应
        c.JSON(200, gin.H{
            "message": "Hello Gin!",
            "status":  "success",
        })
    })

    // 启动服务，监听 8080 端口
    r.Run(":8080")
}

运行服务

go run main.go

输出类似：

[GIN-debug] [WARNING] Creating an Engine instance with the Logger and Recovery middleware already attached.
[GIN-debug] [WARNING] Running in "debug" mode. Switch to "release" mode in production.
 - using env:   export GIN_MODE=release
 - using code:  gin.SetMode(gin.ReleaseMode)
[GIN-debug] GET    /                         --> main.main.func1 (3 handlers)
[GIN-debug] Environment variable PORT is undefined. Using port :8080 by default
[GIN-debug] Listening and serving HTTP on :8080

测试服务

打开浏览器访问 http://localhost:8080 或使用 curl：

curl http://localhost:8080
{"message":"Hello Gin!","status":"success"}

热加载开发

在开发过程中，每次修改代码都需要重启服务，这很繁琐。可以使用 fresh 工具实现热加载：

go install github.com/pilu/fresh@latest

使用 fresh 启动服务：

fresh

现在修改代码后会自动重新编译并重启服务。

[图示：Gin Logo 旁边展示终端运行状态，左侧显示代码编辑界面，右侧显示 curl 请求成功返回 JSON 响应]

小结

本文介绍了如何快速搭建一个基础的 Gin Web 服务：

  1. 安装 Go 和 Gin 框架
  2. 创建简单的路由处理函数
  3. 启动服务并测试
  4. 使用 fresh 实现热加载开发

Gin 的 gin.Default() 会自动添加 Logger 和 Recovery 中间件，r.Run() 启动 HTTP 服务器。这是最简单但完整的 Gin 应用结构。
