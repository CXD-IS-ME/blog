Gin 路由详解：参数传递与分组

2026-06-02

引言

路由是 Web 框架的核心功能之一，负责将 HTTP 请求映射到对应的处理函数。Gin 提供了强大而灵活的路由系统，支持多种参数传递方式和路由分组功能。

路径参数

路径参数是 URL 路径的一部分，用于传递动态值：

package main

import "github.com/gin-gonic/gin"

func main() {
    r := gin.Default()

    // 单个路径参数
    r.GET("/user/:id", func(c *gin.Context) {
        id := c.Param("id")
        c.JSON(200, gin.H{"user_id": id})
    })

    // 多个路径参数
    r.GET("/user/:id/post/:post_id", func(c *gin.Context) {
        userId := c.Param("id")
        postId := c.Param("post_id")
        c.JSON(200, gin.H{
            "user_id":  userId,
            "post_id": postId,
        })
    })

    r.Run(":8080")
}

测试：

curl http://localhost:8080/user/123
{"user_id":"123"}

curl http://localhost:8080/user/123/post/456
{"user_id":"123","post_id":"456"}

查询参数

查询参数是 URL 中 ? 后面的键值对：

r.GET("/search", func(c *gin.Context) {
    keyword := c.Query("keyword")
    page := c.DefaultQuery("page", "1")
    limit := c.DefaultQuery("limit", "10")
    
    c.JSON(200, gin.H{
        "keyword": keyword,
        "page":    page,
        "limit":   limit,
    })
})

测试：

curl "http://localhost:8080/search?keyword=golang&page=2"
{"keyword":"golang","limit":"10","page":"2"}

POST 表单数据

处理表单提交：

r.POST("/login", func(c *gin.Context) {
    username := c.PostForm("username")
    password := c.PostForm("password")
    
    c.JSON(200, gin.H{
        "username": username,
        "password": password,
    })
})

测试：

curl -X POST http://localhost:8080/login \
  -d "username=admin&password=123456"
{"password":"123456","username":"admin"}

路由分组

使用路由分组组织相关的 API：

func main() {
    r := gin.Default()

    // API v1 分组
    v1 := r.Group("/api/v1")
    {
        // GET /api/v1/users
        v1.GET("/users", func(c *gin.Context) {
            c.JSON(200, gin.H{"message": "get users"})
        })
        
        // POST /api/v1/users
        v1.POST("/users", func(c *gin.Context) {
            c.JSON(200, gin.H{"message": "create user"})
        })

        // 用户子分组
        users := v1.Group("/users")
        {
            // GET /api/v1/users/:id
            users.GET("/:id", func(c *gin.Context) {
                c.JSON(200, gin.H{"user_id": c.Param("id")})
            })
            
            // PUT /api/v1/users/:id
            users.PUT("/:id", func(c *gin.Context) {
                c.JSON(200, gin.H{"message": "update user", "id": c.Param("id")})
            })
        }
    }

    // API v2 分组
    v2 := r.Group("/api/v2")
    {
        v2.GET("/users", func(c *gin.Context) {
            c.JSON(200, gin.H{"message": "v2 get users"})
        })
    }

    r.Run(":8080")
}

测试：

curl http://localhost:8080/api/v1/users
{"message":"get users"}

curl http://localhost:8080/api/v1/users/123
{"user_id":"123"}

curl http://localhost:8080/api/v2/users
{"message":"v2 get users"}

路由匹配优先级

Gin 的路由匹配遵循以下规则：

  1. 静态路径优先匹配
  2. 带参数的路径次之
  3. 通配符路径（*path）最后匹配
r.GET("/user/:id", func(c *gin.Context) {
    c.JSON(200, gin.H{"type": "param", "id": c.Param("id")})
})

r.GET("/user/profile", func(c *gin.Context) {
    c.JSON(200, gin.H{"type": "static"})
})

r.GET("/user/*action", func(c *gin.Context) {
    c.JSON(200, gin.H{"type": "wildcard", "action": c.Param("action")})
})

flowchart TD
    A[请求到达] --> B{路径匹配}
    B -->|静态路径| C[精确匹配]
    B -->|带参数路径| D[:id 匹配]
    B -->|通配符| E[*path 匹配]
    C --> F[执行处理函数]
    D --> F
    E --> F

小结

本文介绍了 Gin 路由的核心功能：

  1. 路径参数：使用 :param 定义，通过 c.Param() 获取
  2. 查询参数：使用 c.Query() 获取，c.DefaultQuery() 设置默认值
  3. POST 表单：使用 c.PostForm() 获取表单字段
  4. 路由分组：使用 r.Group() 组织相关 API，支持嵌套分组
  5. 匹配优先级：静态 > 参数 > 通配符

路由分组是组织大型项目 API 的重要方式，可以有效管理不同版本的接口。
