常见并发 Bug 与预防

引言

并发编程是 Go 语言的核心优势，但并发 Bug 也更容易出现。本文将介绍常见的并发 Bug 类型，包括数据竞争、死锁、闭包陷阱等，并提供相应的预防方法。

知识点概览

1. 数据竞争

多个 goroutine 同时访问共享数据，至少有一个是写操作。

2. 死锁

两个或多个 goroutine 互相等待对方释放资源。

3. 闭包陷阱

在循环中创建 goroutine 时，闭包捕获的变量可能是共享的。

4. Map 并发写入

Go 的 map 不支持并发写操作。

小结

本文介绍了常见的并发 Bug 和预防方法：

  • 数据竞争：使用 sync.Mutex 或 sync.RWMutex 保护共享数据
  • 闭包陷阱：将循环变量作为参数传递给 goroutine
  • Map 并发写入：使用互斥锁保护 map 操作
  • 死锁：确保 goroutine 按相同顺序获取锁

使用 go run -race 可以检测数据竞争问题。
