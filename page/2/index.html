  • 路由分组：支持 URL 分组，便于管理 API 版本
  • 错误处理：提供统一的错误处理机制

  • Signature：对前两部分进行签名

2. 生成 Token

使用 github.com/dgrijalva/jwt-go 库生成 JWT。

3. 验证 Token
